# Movies-Mint
streaming app 
Movie Mint — Local Video Files
Place your own legally obtained MP4 video files in this directory.

Expected filenames:

inception.mp4
interstellar.mp4
the-dark-knight.mp4
the-matrix.mp4
avatar.mp4
toy-story.mp4
finding-nemo.mp4
coco.mp4

john-wick.mp4

The website will be developed to display movie metadata even when the corresponding video is unavailable.

Use only video content that you own or are authorized to use.
